# drawDB 画布操作 vs Figma 对照表

本文档整理 drawDB 编辑器的画布操作与 Figma 的差异，以及本分支（`feat/space-pan`）中已对齐 Figma 的部分。

- Windows / Linux 使用 `Ctrl`，macOS 对应 `Cmd`（代码中以 `mod` 绑定）。
- 状态说明：✅ 与 Figma 一致　🆕 本分支新增　⚠️ 行为不同（有意保留）　❌ 尚未支持
- 焦点在输入框、文本框、注释编辑区或 DBML/SQL 代码编辑器内时，以下快捷键**都不会触发**，按键保持原本的文字输入行为。

---

## 1. 平移（移动画布）

| 操作                      | Figma                  | drawDB（原本）       | drawDB（本分支）                                   | 状态                     |
| ------------------------- | ---------------------- | -------------------- | -------------------------------------------------- | ------------------------ |
| 按住空格 + 左键拖动       | 平移                   | 不支持               | 平移；按在表格、注释、区域上也只平移，不会拖动元素 | 🆕                       |
| 中键拖动                  | 平移                   | 平移                 | 平移                                               | ✅                       |
| 右键拖动                  | 不平移（打开右键菜单） | 平移                 | 平移                                               | ⚠️ drawDB 额外支持，保留 |
| 鼠标滚轮                  | 垂直滚动               | 垂直滚动             | 垂直滚动                                           | ✅                       |
| `Shift` + 滚轮            | 水平滚动               | 水平滚动             | 水平滚动                                           | ✅                       |
| 触控板双指上下 / 左右滑动 | 任意方向平移           | 只能上下（左右无效） | 任意方向平移                                       | 🆕                       |
| 方向键（未选中元素时）    | 无                     | 平移 60px            | 平移 60px                                          | ⚠️ drawDB 额外支持，保留 |

## 2. 缩放

| 操作                             | Figma                  | drawDB（原本）               | drawDB（本分支）                                                                                                 | 状态                 |
| -------------------------------- | ---------------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------- | -------------------- |
| `Ctrl` + 滚轮                    | 以光标为中心缩放       | 每格固定 5%                  | 每格固定 5%（行为不变）                                                                                          | ✅                   |
| 触控板双指捏合                   | 按幅度平滑缩放         | 每个事件固定 5%，很快、很跳  | 按幅度平滑缩放，以光标为中心                                                                                     | 🆕                   |
| 放大                             | `Ctrl` + `=`（或 `+`） | `Ctrl` + `↑`                 | `Ctrl` + `=` / `Ctrl` + `Shift` + `=` / `Ctrl` + `;`（JIS 键盘的 `+`）/ `Ctrl` + 数字键盘 `+`；`Ctrl` + `↑` 保留 | 🆕                   |
| 缩小                             | `Ctrl` + `-`           | `Ctrl` + `↓`                 | `Ctrl` + `-` / `Ctrl` + 数字键盘 `-`；`Ctrl` + `↓` 保留                                                          | 🆕                   |
| 缩放到 100%                      | `Shift` + `0`          | 无（`Enter` 会同时重置位置） | `Shift` + `0`（只改缩放，保持当前位置）                                                                          | 🆕                   |
| 缩放到显示全部内容               | `Shift` + `1`          | `Ctrl` + `Alt` + `W`         | `Shift` + `1`；`Ctrl` + `Alt` + `W` 保留                                                                         | 🆕                   |
| 缩放到选中元素                   | `Shift` + `2`          | 无                           | `Shift` + `2`                                                                                                    | 🆕                   |
| 重置视图（缩放 100% 并回到原点） | 无                     | `Enter`                      | `Enter`                                                                                                          | ⚠️ drawDB 独有，保留 |

## 实现说明

改动的文件：

- `src/components/EditorCanvas/Canvas.jsx`
  - 空格 + 拖动平移（在捕获阶段拦截指针事件，所以元素不会被拖动）
  - `Shift` + 点击 / 框选加选
  - 滚轮处理：支持 `deltaX`；触控板捏合按幅度缩放；Firefox 的行 / 页单位换算成像素
- `src/components/EditorHeader/ControlPanel.jsx`
  - 新增快捷键：`Shift+0/1/2`、`Ctrl+=/-`、`Ctrl+A`、`Esc`、`Backspace`、`Ctrl+Shift+Z`、`Shift+方向键`
  - 删除支持多选；注释和区域按 id 从大到小删除，避免删除后 id 重排导致删错
  - 方向键：有选中元素时移动元素（记入撤销历史），否则平移画布
  - `fitToView` 支持只按指定元素计算范围（用于 `Shift+2`），没有元素时不再算出 NaN
  - 撤销删除表格时跳过已经恢复的关系，避免同时删除两张有关系的表后，撤销时关系被重复添加
  - 菜单上的快捷键提示同步更新

## 已知限制

- 快捷键按**物理按键**匹配（`KeyboardEvent.code`）。`Ctrl+=` 在 JIS 键盘上对应 `^` 键，所以额外绑定了 `Ctrl+;`（JIS 的 `+` 所在键）。
- 焦点在按钮上时，空格会被用于平移，不会再触发按钮点击。
- 每按一次方向键记一条撤销记录；Figma 会把连续移动合并成一条，这里没有合并。
- 剪切（`Ctrl+X`）仍然只处理单个元素，和复制保持一致。
